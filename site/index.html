Which stores let a shopping agent check out?

One agent, 30 real stores, one task: find the product, add it to the cart, check out as a guest, stop before payment. Only the browser changed. Anchor got the agent past the front door at 25 stores, Chromium on a laptop at 12. Once in, the agent finished checkout at 19. The other 6 stopped on an agent stall or on a store with no guest checkout.

Why runs stopped

The 11 stores that did not finish, grouped by what ended most of their runs on the best setup.

  • Stalled at checkoutAgent can fix
    4stores
    • autozone.com
    • diy.com
    • lookfantastic.com
    • microcenter.com

    The browser got past the front door and the agent reached the cart or the checkout. It then did not get the form accepted, or used up its steps. A stronger shopping agent can finish here with no change to the browser.

  • Sign-in requiredNeeds a signed-in run
    2stores
    • amazon.com
    • walmart.com

    The store has no guest checkout. The agent built the cart, then checkout asked for an account. The task says guest only, so the run stops there. This is the store’s rule, not a block.

  • Stopped by PerimeterXBrowser has to get in
    2stores
    • target.com
    • wayfair.com

    PerimeterX is a bot-detection service. It challenged the browser before the agent could reach a product, so nothing the agent does changes the result.

  • Stopped by an edge blockBrowser has to get in
    1store
    • michaels.com

    The store’s network edge refused the request before any page loaded. The agent never had a page to act on.

  • Stopped by ImpervaBrowser has to get in
    1store
    • smythstoys.com

    Imperva is a bot-detection service. It challenged the browser before the agent could reach a product, so nothing the agent does changes the result.

  • Store served an error pageCause not known yet
    1store
    • Eebay.com

    The store answered with its own error page instead of the storefront, on every setup tried. It may be a block that looks like an outage, or a store fault.

How to read this

What ran

A small reference agent, a Claude tool-use loop on claude-opus-5-5, with the same grader for every row. The agent is a bundled example, not a tuned shopper.

What counts

The grader reads the browser, not the agent's claim. A run passes when the store accepts the placeholder shipping details. Runs where the browser itself failed are not graded.

What to hold back

Three runs per store per setup is a small sample, and stores change between runs. The best setup is picked after the runs, so it shows what to use, not one configuration tested everywhere.
